# YuNuo – 密码与 API Key 生成器

适用于当前稳定版 Chrome 和 Edge 的本地密码 / API Key 生成插件。无需安装依赖、构建或启动服务。

## 安装

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择本项目的 **extension** 文件夹（不是仓库根目录）。
4. 将插件固定到工具栏，点击图标开始使用。

修改代码后，在扩展管理页面点击「重新加载」，再重新打开弹窗。

## 语言

界面、插件名称、工具栏提示与错误消息自动跟随浏览器界面语言。目前支持简体中文（zh_CN）和英文（en），其他语言回退到英文。修改浏览器界面语言并按浏览器要求重启后，重新打开插件即可生效；无需手动切换，也不需要网络翻译。

添加语言时，在 `extension/_locales/<语言代码>/messages.json` 中提供与英文相同的消息键。

## 功能

- 密码长度 4–128 位，默认 16 位。大写、小写、数字、特殊符号自由组合，每种已选类型至少出现一次。
- 特殊符号：`!@#$%^&*()-_=+[]{};:,.?`。
- API Key 为 `sk-` 加 48 位随机大小写字母与数字，共 51 位。需要在目标平台配置或录入后才能作为凭据使用。
- 打开弹窗、切换模式、有效修改配置、点击刷新均会生成新结果；点击复制写入系统剪贴板。
- 本地只保存长度和字符开关；不保存生成结果，不发送网络请求。复制后的内容保留在系统剪贴板，直到用户替换。

## 测试

使用 Node.js 20 或以上版本运行：

```sh
npm test
```

无需 `npm install`。测试包含全部 15 种字符组合、边界与无效长度、API Key 格式、随机索引拒绝采样、字符覆盖重新采样和存储适配。

## 人工验收

请分别在 Chrome 和 Edge 执行：

- 分别使用简体中文、英文浏览器界面语言验证名称、按钮、字符数量、输入错误、复制反馈及存储错误均完整翻译；其他语言回退英文。
- 首次打开默认生成 16 位密码，四种字符全部勾选。
- 滑块和数字输入联动；4 位、128 位均完整显示和复制。
- 输入空值、非整数、3、129 时提示错误、清空结果并禁用复制与刷新；改回合法值后自动生成。
- 遍历字符开关；最后一种无法取消且提示原因；结果符合已选类型。
- 切换 API Key，确认前缀和 51 位总长度；刷新及复制有效。
- 对比粘贴结果与显示结果，确认复制不截断；模拟拒绝剪贴板访问时显示失败反馈，可手动选中复制。
- 关闭重开，保留有效密码设置并生成新结果；检查 `chrome.storage.local` 中只有 `settings`。
- 使用 Tab、空格、方向键操作，检查焦点可见，标签页可切换，复制状态可被读屏读取。
- 在弹窗开发者工具中检查无错误、无外部网络请求。

## 实现

Manifest V3，原生 HTML/CSS/ES Modules。随机源为 Web Crypto `crypto.getRandomValues()`；拒绝不完整索引桶以消除取模偏差，密码候选串不满足类型覆盖时重新采样。

仅申请 `storage`（保存偏好）权限；复制在用户点击时直接调用 Clipboard API，无需 `clipboardWrite`，安装时不出现剪贴板权限警告。不申请站点权限。所有代码与资源随扩展提供。

## 图标

`design/icons/` 存放各尺寸图标的 SVG 源文件，`extension/icons/` 中的 PNG 由其按原尺寸导出。128 保留四周 16px 透明边距（商店规范）；48、32、16 裁掉边距并加粗星号笔画，保证小尺寸可辨认。修改图标时先改 SVG，再重新导出对应 PNG。

## 商店素材

`design/store/` 存放 Chrome 应用商店素材，中英文各一套：截图 `screenshot-<语言>-<模式>.png`（1280×800）和宣传小图 `promo-small-<语言>.png`（440×280）。截图中的弹窗是插件真实页面，文案和排版在 `design/store/src/`。界面或文案修改后，在 macOS 上运行 `sh design/store/build.sh` 重新导出（需要 Google Chrome 和 Python 3）。
